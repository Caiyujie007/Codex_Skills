# Verification Checklist

Use this before delivering any facts extracted from images.

- [ ] Only authorized source images were used.
- [ ] Original-resolution pixels were inspected.
- [ ] Reading order and row/column associations were established visually.
- [ ] At least two independent OCR passes were compared.
- [ ] Ambiguous regions were cropped or zoomed and checked again.
- [ ] No values were inferred from patterns or neighboring records.
- [ ] Leading zeros, units, signs, decimals, and punctuation were preserved.
- [ ] Every record is traceable to a source row or region.
- [ ] Unresolved values are marked `待确认`.
- [ ] Output record count and order match the source.
- [ ] The final artifact was reopened and checked.
